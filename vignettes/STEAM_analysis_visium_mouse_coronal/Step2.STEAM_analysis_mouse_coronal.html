Step2. STEAM analysis

In this vignette we use Seurat v5 to create a Seurat object and then run STEAM.

We show how to run STEAM on a Visium mouse coronal brain section from 10X Genomics, which can be accessed here: https://www.10xgenomics.com/datasets/mouse-brain-section-coronal-1-standard-1-1-0.

We use ranked gene lists from Open Targets (v.25.06) for Alzheimer’s disease, ALZ, (MONDO_0004975).

Please note that some steps have been pre-run in a separate vignette to generate the permutation matrices needed and to only keep genes in the gene lists that are present in the Seurat object after QC filtering.
